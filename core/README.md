# Citizen core

The pet. One C99 translation unit set, no libc at runtime, no malloc, one static instance. The host owns time, input and storage; the core owns the pet and the pixels. It renders into a static 240x240 framebuffer of 8-bit palette indices (57,600 bytes) and the host converts that to RGB565 on the way to the panel.

The same six files build three ways: native with clang for the tests, wasm32 freestanding for the browser simulator in `sim/`, and riscv for the ESP32-C3 firmware in `firmware/`. Nothing in here knows which one it is running on.

Facts in this document come from `citizen.h`, `citizen.c`, `screens.c`, `gfx.c` and the output of `make test`, `make bench` and `make soak` on 16 Oct 2026. Every screen is pictured in the [screen gallery](../docs/screens/README.md).

## Layers

```
  host (firmware/src/main.cpp, sim/, tests/)
  time, touch, storage, WiFi, backlight, SPI push
        |  cz_tick / cz_touch / cz_set_* / cz_message / cz_checkin
        v
 +-------------------------------------------------------------+
 | citizen.c   state machine: hearts, timers, gestures, screens |
 |             save blob, Settings wheel, view key + clip rects  |
 +-------------------------------------------------------------+
        |  struct cz_view              ^ cz_anim, cz_anim_box
        v                              |
 +-------------------------------------------------------------+
 | screens.c   one function per screen, skyline, banner, QR    |
 +-------------------------------------------------------------+
        |  cz_rect / cz_blit / cz_text / cz_icon / cz_dim / cz_clip
        v
 +-------------------------------------------------------------+
 | gfx.c       palette, 3x5 font, 8x8 icons, clipped fills,    |
 |             dirty row span, stat counters                   |
 +-------------------------------------------------------------+
        |  cz_fb[240*240] palette indices
        v
  host reads cz_framebuffer() + cz_palette(), pushes cz_dirty_rows()

 sprites.c    3 creatures x 8 poses x 64x64, generated by tools/pack_sprites.py
 qrcodegen.c  Nayuki's QR encoder, used by the QR screen
 libc_shim.c  memset/memcpy for the wasm build only (CZ_FREESTANDING)
```
